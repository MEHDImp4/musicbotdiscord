# Governance / Gouvernance

## 🇬🇧 English

### Roles

- **Maintainer** — has write access, reviews and merges pull requests, cuts releases, and makes final decisions. Currently: [@MEHDImp4](https://github.com/MEHDImp4).
- **Contributor** — anyone who opens issues, discussions, or pull requests.

### Decision making

The project uses a **maintainer-led** model: the maintainer has the final say. In practice, most decisions are made openly in issues and pull requests, and community feedback is strongly encouraged.

### How changes land

1. Open an issue (for non-trivial changes) to discuss the idea.
2. Fork and open a pull request following [CONTRIBUTING.md](./CONTRIBUTING.md).
3. CI (build + tests) must pass.
4. The maintainer reviews and merges (squash).

### Becoming a maintainer

Consistent, high-quality contributions (code, reviews, triage, documentation) build trust. When that happens, the maintainer may invite a contributor to become a maintainer. There is no fixed quota.

### Changes to this document

Governance changes are proposed via pull request and approved by the maintainer.

## 🇫🇷 Français

### Rôles

- **Mainteneur** — accès en écriture, relit et fusionne les pull requests, publie les versions et prend les décisions finales. Actuellement : [@MEHDImp4](https://github.com/MEHDImp4).
- **Contributeur** — toute personne qui ouvre des issues, discussions ou pull requests.

### Prise de décision

Le projet suit un modèle **dirigé par le mainteneur** : le mainteneur a le dernier mot. En pratique, la plupart des décisions se prennent ouvertement dans les issues et pull requests, et les retours de la communauté sont fortement encouragés.

### Comment les changements arrivent

1. Ouvre une issue (pour les changements non triviaux) pour discuter de l'idée.
2. Fork puis ouvre une pull request en suivant [CONTRIBUTING.md](./CONTRIBUTING.md).
3. La CI (build + tests) doit passer.
4. Le mainteneur relit et fusionne (squash).

### Devenir mainteneur

Des contributions régulières et de qualité (code, relectures, triage, documentation) construisent la confiance. Le moment venu, le mainteneur peut inviter un contributeur à devenir mainteneur. Il n'y a pas de quota fixe.

### Modifications de ce document

Les changements de gouvernance sont proposés via pull request et approuvés par le mainteneur.
