# Support

## 🇬🇧 English

Need help with **Pulse**? Here is where to go:

| I want to… | Where |
|---|---|
| Ask a question / get help | [GitHub Discussions](https://github.com/MEHDImp4/pulse/discussions) |
| Report a bug | [Open a bug report](https://github.com/MEHDImp4/pulse/issues/new?template=bug_report.yml) |
| Request a feature | [Open a feature request](https://github.com/MEHDImp4/pulse/issues/new?template=feature_request.yml) |
| Report a security issue | See [SECURITY.md](./SECURITY.md) (private) |
| Contribute code | See [CONTRIBUTING.md](./CONTRIBUTING.md) |
| Read the docs | [README](./README.md) |

Before opening an issue, please search existing issues and discussions.
