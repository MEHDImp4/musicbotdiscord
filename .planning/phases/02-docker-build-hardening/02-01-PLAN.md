<task type="auto">
  <name>Task 2: Add init and stop_grace_period to docker-compose.yml</name>
  <files>docker-compose.yml</files>
  <action>
Add two configuration options to the musicbot service in docker-compose.yml (per BUILD-03, BUILD-04):

1. `init: true` — Makes Docker inject tini as PID 1. This forwards SIGTERM to the node process and reaps zombie processes from yt-dlp children. Without this, Node.js as PID 1 silently ignores SIGTERM.

2. `stop_grace_period: 15s` — Allows 15 seconds for the bot to shut down before Docker sends SIGKILL. This accounts for:
   - yt-dlp mid-download cleanup (5-10s)
   - FFmpeg buffer flush
   - Discord voice disconnect acknowledgment
   - Buffer beyond worst case

Add these after `restart: unless-stopped` and before `env_file:`.

Do NOT:
- Set stop_grace_period higher than 30s (excessive)
- Remove existing volume mounts or network config
- Add version: "3.x" (obsolete in Compose v2+)

Reference: Docker compose docs, krallin/tini README
  </action>
  <verify>
    <automated>docker compose config | grep -E "init:|stop_grace_period:"</automated>
  </verify>
  <done>
- docker-compose.yml has `init: true` under musicbot service (BUILD-03 satisfied)
- docker-compose.yml has `stop_grace_period: 15s` under musicbot service (BUILD-04 satisfied)
- `docker compose config` validates without errors
- Existing configuration (env_file, volumes, networks) unchanged
  </done>
